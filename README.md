# TrustLens – Multimodal AI Lie Detection (Starter Build)

## What works out-of-the-box
- Audio feature extraction (MFCC + pitch + speaking rate)
- Audio deception classifier (RandomForest)
- FastAPI backend endpoint
- Clean project structure (resume-ready)

> ⚠️ Ethical Disclaimer:
This system provides probabilistic insights only and must NOT be used for legal or forensic decisions.

## How to Run (Windows)
1. Create & activate venv
2. Install requirements
3. Add WAV files
4. Train model
5. Run API

See detailed steps at the end.
